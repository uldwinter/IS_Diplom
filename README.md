# Банк индивидуальных достижений

React/Vite + Express + PostgreSQL. Данные и права определяются API; браузер хранит только полученный снимок в памяти. Сессия — отзываемый HttpOnly cookie. Пароли, файлы и решения куратора не хранятся в localStorage.

## Запуск

Нужны Node.js 22.16+ и PostgreSQL 16+. Установите зависимости отдельно для клиента и сервера:

```sh
npm ci
npm ci --prefix server
cp server/.env.example server/.env
```

Заполните параметры PostgreSQL в `server/.env`. Выполняйте серверные команды из каталога `server`, чтобы dotenv загрузил этот файл:

```sh
cd server
npm run migrate
npm run bootstrap
npm start
```

Параметры первой учётной записи администратора описаны в `server/.env.example` и `server/README.md`. Готовых рабочих паролей в коде нет. Миграция переносит существующие серверные записи в новую схему, сохраняя исходные таблицы. Заполнение демонстрационными данными запускается только отдельной командой; обычный запуск ничего не пересоздаёт.

В другом терминале из корня:

```sh
npm run dev
```

Vite проксирует `/api` на порт 8080. Куратор создаётся администратором, ученик подаёт регистрацию. Две независимые браузерные сессии получают данные из общей БД; открытая страница обновляется каждые 15 секунд и при возвращении в окно. При потере подключения формы не сообщают об успешном сохранении.

## Что реализовано

- Серверные роли и отзыв сессий при блокировке/смене прав и пароля.
- Полная регистрация, решение куратора и серверные проверки полей.
- Документы PDF/JPEG/PNG с проверкой сигнатуры и размера, отдельная таблица PostgreSQL с бинарными данными и защищённое скачивание.
- Серверное начисление по версии правил категории/уровня; число от браузера не принимается как источник баллов. Результат сохраняется, но отдельные коэффициенты для победителя/призёра не выдумываются без школьного положения.
- Защита от повторного учёта, доработка отклонённой заявки, отмена подтверждения с причиной, история решений.
- Учебные годы и четверти, рейтинг с общими местами при равных баллах, поиск без пересчёта мест, исторические классы и перевод учеников.
- Архивирование вместо удаления результатов, импорт CSV с предварительным просмотром и проверкой дублей.
- Серверные резервные копии с документами, проверка восстановления и завершение старых сессий.
- CSV/HTML и отдельная печатная форма для PDF; экспорт не выдаёт HTML или CSV за настоящий DOCX/XLSX.

Учебный год: 1 сентября — 31 августа. Границы четвертей по умолчанию явно показаны в интерфейсе; адаптация календаря школы находится в `src/app/lib/academic.ts` (`DEFAULT_QUARTERS`). Год и период выбираются пользователем. Расчёты достижений используют дату события, а не дату подачи.

## Проверки

```sh
npm run check
```

Команда включает TypeScript, поведенческие тесты клиента и сервера, проверку исходников и production-сборку. В серверных тестах используется настоящий встроенный PostgreSQL (PGlite) и HTTP-сценарии с независимыми сессиями. Проверки выполняются в GitHub Actions и в команде сборки Vercel.

## Публикация

См. `docs/PRODUCTION.md`. Для Vercel предусмотрен `api/index.mjs`; миграции выполняются явно до переключения версии. Preview не должен подключаться к рабочей базе. Сначала проверьте перенос и полный сценарий на отдельной БД/ветке. Изменения в GitHub сами по себе не переносят локальные записи из браузеров пользователей: для них сохраните старые JSON-копии отдельно и подготовьте проверенный импорт, не доверяя локальным ролям и хешам паролей.

Резервные копии содержат персональные данные и серверные хеши паролей. Храните их вне публичного репозитория. Подробности формата, восстановления и ограничений платформы — в `server/README.md`.
